# 1.1.1-nuzlocke Release Notes

`1.1.1-nuzlocke` is an evolution-accessibility update over
`1.1.0-nuzlocke`. It replaces special evolution conditions that could be
impossible or excessively grind-heavy in Emerald's world, with randomized
learnsets, or during this hack's shortened Nuzlocke campaign.

## Nincada and Shedinja

Nincada's evolution rules are intentionally unchanged. It evolves into Ninjask
at level 20 and also creates Shedinja when the party has an open slot and the
Bag contains a regular Poké Ball. One Poké Ball is consumed.

This behavior was verified in the boxed-evolution code path and documented in
this update. When Storage `LEVEL TO CAP` evolves a boxed Nincada, Ninjask returns
to the original box slot and Shedinja is added to the party. A full party or a
missing regular Poké Ball prevents Shedinja without blocking Ninjask.

## Regression protection

The evolution-table test now scans every enabled species and rejects the
audited inaccessible or grind-heavy condition categories. Nincada's Poké Ball
check is the sole permitted Bag-item-count evolution condition.

Validation completed for this release:

- All 60 focused randomizer tests pass.
- All four focused level-cap tests pass.
- The production ROM builds successfully.
- The source and documentation pass `git diff --check`.

The boxed Nincada interaction still has explicit emulator-validation checklist
cases for successful Shedinja creation, a full party, and a missing Poké Ball.

## Save compatibility

This update changes evolution-table rules only. It does not change the saved
randomizer seed format or deterministic randomizer mappings, so existing
`1.1.0-nuzlocke` saves remain compatible.
